LN STUDIO v3.0

1. Subir todos los archivos a GitHub reemplazando los anteriores.
2. NO volver a crear _redirects ni wrangler.jsonc.
3. En Supabase > SQL Editor ejecutar supabase-v3.sql completo.
4. Abrir /admin e iniciar sesión con lnstudio.eventos@gmail.com.
5. El aniversario real queda en:
   /evento.html?token=33333333-3333-4333-8333-333333333333
6. El catálogo público sigue mostrando únicamente modelos ficticios.
7. Para dar acceso a un cliente: abrir el evento > Accesos > agregar correo y rol.
8. El cliente entra desde /admin con ese correo. Puede usar contraseña o enlace mágico.
9. Los QR se generan después de confirmar asistencia en una invitación real.
10. El escáner está en /scanner.html?event=ID_EVENTO.

Roles:
owner: control total de LN Studio.
staff: equipo interno.
client_admin: administra su evento.
event_staff: escanea y gestiona accesos.
