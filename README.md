# LN Studio v4.4

Plataforma de invitaciones digitales con:

- Panel general de LN Studio.
- Panel privado por evento para clientes.
- RSVP, pases QR y escáner exclusivo por evento.
- Diseñador avanzado exclusivo para owner/staff de LN Studio.
- Carga de logos, imágenes, galería y música mediante Supabase Storage.
- Paletas para fiestas, infantiles, bodas, temáticas y empresariales.
- Tipografías, tamaños, colores, contraste, animaciones y orden de secciones.
- Invitaciones privadas y responsive.

Todos los archivos para GitHub se mantienen directamente en una sola raíz.
